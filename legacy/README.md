# Legacy material

This preserves the original subset implementation and historical evidence for
comparison only. It is excluded from maintained regression and synthesis.

- `rtl/`: former `src/` implementation.
- `tb/`: former top-level waveform tests. `main_tb.v` remains as an empty
  historical placeholder and is not a maintained test.
- `docs/`: original diagrams and pre-handshake OpenROAD screenshots.

Current work is under `rtl/`, `tb/unit/`, `tb/core/`, and
`docs/openroad-handshake-results/`.
